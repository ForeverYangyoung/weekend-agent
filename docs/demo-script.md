# Demo 剧本

详细场景定义见 [`01-题目工程拆解.md`](../01-题目工程拆解.md)（场景 A 家庭 / 场景 B 朋友）。

## 幕 1 · 家庭场景（P0）

| 项 | 内容 |
|----|------|
| 输入示例 | 「周六下午带老婆和 5 岁孩子出门 4 小时，老婆减肥，别太远」 |
| 预期 | Profiler 识别 family；Planner 产出儿童友好 + 低卡组合；Top 方案可展示 |
| 演示 | CLI 或 Playground 输入 → 看 trace / 方案卡片 |

## 幕 2 · 朋友场景

| 项 | 内容 |
|----|------|
| 输入示例 | 「下午和朋友 4 个人逛街吃饭，预算人均 200」 |
| 预期 | friends 场景、4 人、预算约束进入打分 |

## 幕 3 · 失败与补偿（答辩核）

| 项 | 内容 |
|----|------|
| 触发 | `force_failure` 或 Mock 满座/下单失败 |
| 预期 | 备选方案或 Compensator 回滚；行程卡标注部分失败 |
| 讲解点 | 「想 → 查 → 定 → 通知」闭环 + 可观测 trace |

每幕补充：前置数据、点击顺序、屏幕关键文案（Super Dev UI 阶段写入 `output/weekend-agent-uiux.md`）。
